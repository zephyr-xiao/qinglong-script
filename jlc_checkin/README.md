# 嘉立创签到 - 青龙面板脚本

自动完成嘉立创(立创商城 m.jlc.com)每日签到:

- **每日签到**:领取金豆奖励
- **第七天奖励**:签到周期第七天自动领取 8 金豆券
- **余额查询**:签到后刷新金豆余额并随通知推送

移植自 GitHub [Foticing/LC-AutoSign](https://github.com/Foticing/LC-AutoSign),按青龙面板规范重写。

## 特性

- AccessToken 认证,轻量无浏览器依赖(仅 `requests`)
- 已签到自动跳过,可安全重复执行(幂等)
- 多账号支持(换行分隔)
- Token 失效自动检测,推送告警提醒重新抓包
- 网络抖动自动重试(3 次线性退避)
- 复用青龙 `notify.py` 推送

## 快速开始

### 1. 青龙面板安装依赖

在青龙「依赖管理」-「Python」中安装:

```
requests
```

### 2. 配置环境变量

| 变量名 | 必填 | 说明 |
|--------|------|------|
| `JLC_TOKEN` | ✅ | AccessToken,多账号用换行分隔 |
| `JLC_PROXY` | ❌ | HTTP 代理,如 `http://172.17.0.1:7890` |
| `JLC_NOTIFY` | ❌ | 是否推送,默认 `true` |
| `JLC_NOTIFY_ONLY_FAIL` | ❌ | 全部成功时静默,默认 `false` |
| `JLC_TIMEOUT` | ❌ | 请求超时秒数,默认 `30` |
| `JLC_DEBUG` | ❌ | 调试模式,输出接口响应细节,默认 `false` |

### 3. 获取 AccessToken

1. **用 Chrome 浏览器**打开 https://m.jlc.com 并登录嘉立创账号
   (必须 Chrome:Edge 的设备模拟抓不到此请求头,实测确认)
2. 按 `F12` 打开开发者工具,按 **Ctrl+Shift+M** 切换移动设备模拟后刷新页面
   (电脑直连会跳转 PC 版页面,PC 端请求不发此请求头)
3. 切到「网络」(Network)标签,刷新页面,点击任意发往 `m.jlc.com` 的请求
4. 在「请求标头」中找到 `X-JLC-AccessToken`,复制其值

> 💡 也可以用手机抓包工具(如 Stream / HttpCanary)从嘉立创 App 内抓取。
> **拿到 Token 后请勿在网页或 App 上手动退出账号**,否则 Token 立即失效。
> Token 正常登录状态下长期有效;若推送提示「Token 已失效」,重新抓取更新环境变量即可。

多账号格式(换行分隔):

```
账号1的AccessToken
账号2的AccessToken
```

### 4. 添加青龙任务

- 命令:`task jlc_checkin/jlc_checkin.py`
- 定时:`40 8 * * *`(每天上午 8:40,可自行调整)

## 常见问题

### Q: 提示「AccessToken 已失效」?
A: 抓包时或在其他设备登录导致 Token 刷新。重新按上述步骤抓取,更新 `JLC_TOKEN` 环境变量。

### Q: 签到显示「第七天签到,领券接口无收益」?
A: 第七天奖励需按活动规则领取,可能当日奖励已被领取或不满足条件,次日观察即可。

### Q: 一天可以跑多次吗?
A: 可以。已签到时脚本自动跳过(幂等),不会有副作用。
